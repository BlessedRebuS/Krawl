Kestrel TMS API v2

OpenAPI 3.1 · base URL https://api.kestrelfreight.nl/v2 · openapi.json

Authentication

All endpoints require a bearer token issued by POST /auth/token. Tokens expire after 24 hours.

curl -H "Authorization: Bearer <token>" \
     https://api.kestrelfreight.nl/v2/orders?status=open&page=1

Endpoints
